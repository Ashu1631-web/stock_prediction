# 📈 Stock Price Prediction using LSTM

This project predicts stock closing prices using an LSTM (Long Short-Term Memory) Neural Network.

## 🚀 Features
- Fetch real-time stock data using Yahoo Finance
- Train LSTM model on historical prices
- Predict future closing price
- Streamlit interactive dashboard

## 🛠 Tech Stack
- Python
- TensorFlow / Keras
- LSTM Neural Network
- Streamlit
- Yahoo Finance API

## ▶ Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
